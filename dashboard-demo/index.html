调用链路与多维用量

用户 → 分组场景 → 路由别名 → 模型账号（1:1 绑定具体模型）· 关系与用量同步下钻
链路关系来自 groups.model_routing；模型账号严格 1:1 绑定上游模型，用量按最终命中的 account_id 归属。
关系口径：分组 1:N 路由别名，路由别名 1:N 候选模型账号，模型账号 1:1 绑定具体模型；用量按最终命中的 account_id 统计，模型名仅作账号属性来源：model_routing + account.model_mapping + UsageLog/tokenstat
