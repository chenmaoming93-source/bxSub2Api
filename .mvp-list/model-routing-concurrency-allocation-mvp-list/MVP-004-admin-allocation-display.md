# MVP-004：管理页面展示候选分配

- Protocol: `mvp-list/v1`
- State: `VERIFIED`
- Estimate: `1 day`
- Dependencies: `MVP-001, MVP-003`

## 目标

在分组和账号管理页面展示候选并发分配、比例和无限制状态。

## 范围

- 分组编辑候选旁显示最大并发、占比和已分配额度；
- 账号列表引用列显示候选并发和占比；
- 编辑账号弹窗显示完整引用信息；
- 账号并发为 0 时显示“不适用（账号不限）”；
- 候选 `null`/缺失时显示“无限制（不参与分配）”；
- 保持标签样式、宽度限制和换行交互。

## 非范围

- 不修改请求限流逻辑；
- 不增加新的全局统计页面。

## 验收标准

- [x] 分组页面能展示具体并发和占比；
- [x] 账号列表能展示引用、并发和占比；
- [x] 编辑账号页面能展示引用、并发和占比；
- [x] `null`/缺失和账号不限状态有明确文案；
- [x] 页面标签不会溢出，多个标签可换行；
- [x] 前端类型检查和相关测试通过。

## 验证计划

- 运行 frontend typecheck；
- 运行分组路由和账号引用相关 Vitest；
- 手动检查 0、正数、`null` 和多引用展示。

## 证据

完成证据：

- 分组编辑器显示候选并发、账号总并发、已分配额度和比例；
- 账号列表及编辑账号引用组件显示具体分配、比例和“不参与分配”状态；
- `npm run typecheck` 通过；
- `npm run test:run -- src/views/admin/__tests__/groupsModelRouting.spec.ts src/api/admin/__tests__/accounts.spec.ts` 通过，4 个测试通过。
